## Agent skills

### Issue tracker

GitHub Issues. Use the `gh` CLI for all operations — create, read, list, label, and close issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Six labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `done`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` at the repo root + `docs/adr/`. See `docs/agents/domain.md`.
